## 3. Model data & aturan inti

### 3.1 SaveData (`lib/storage.ts`)
```ts
Profile{name, age:AgeId, sound, createdAt}
Best{stars, score, accuracy, wpm}
ModProg{materiDone, quizXp, best?, completions, passed?, xpBest?, coinsBest?}
Stats{games, wins, bestWpm, bestCombo, keystrokes, correct}
SaveData{profile, xp, coins, modules:Record<string,ModProg>, stats}
RANKS: Plankton 0, Ikan Kecil 120, Kuda Laut 280, Lumba-Lumba 500, Hiu Muda 800, Megalodon 1200, Legenda Samudra 1700
```

### 3.2 Progress (`lib/progress.ts`) — JANGAN duplikasi aturan di tempat lain
- `sessionPassed(save,id)` = `modules[id].passed === true`
- Sesi LULUS = `won && accuracy >= Session.passAcc`
- `meetingLevel(no)`: 0 Belum | 1 Perunggu (quest lulus) | 2 Perak (quest+drill) | 3 Emas (+juggle)
- `meetingUnlocked(no)`: no≤1 selalu true; else `meetingLevel(no-1) >= 2`
- `applyAttempt(prev, session, result, xpSession, coinsSession)` → `{next, passed, xpAward, coinsAward}`; `xpAward = max(0, xpSession - xpBest)` (anti-farm), best обнов hanya bila stars naik atau (stars sama + score naik), `passed` sticky (`old || new`).
- XP sesi (di `App.finishPractice`): menang → `50 + stars*25 + round(acc/5)`; kalah → `round(score/25)`. Koin: menang → `10 + stars*10 + round(acc/10)`; kalah → 0. Materi: +20 baca pertama, +quizXp kuis pertama.

### 3.3 Sesi & kurikulum
- ID sesi pertemuan: `q:<no>:<kind>` dengan kind `quest|drill|juggle` (+ legacy `misi`). `Session{passAcc}`: quest/drill ≥90, juggle ≥85 (cek `quests.ts` bila ragu).
- `nextMeeting(save)` di `App.tsx`: no terkecil yang `unlocked && level<2`, fallback 16.
- `meetingScreenOf(id)`: `q:<no>:` → `{s:"peta",no}`, else `{s:"dash"}` (dipakai tombol Results "Kembali ke Peta").

## 4. Navigasi / Screen (`App.tsx`)

```ts
type Screen = dash | {peta,no} | {materi,id} | {materi-html,no?} | {game,id,k} | {result,id,r,xp,coins,rankUp,passed}
```

- `dash` → `Dashboard` (HUB + Peta Misi Samudra list MODULES + kartu "Peta Pertemuan 16×").
- **`peta` → `Pertemuan` HALAMAN KHUSUS (bukan modal).** Dibuka dari Dashboard `onPeta → {s:"peta", no:nextMeeting}`. Lihat §6 untuk detail refactor.
- `materi-html` → `MateriHtml` (dokumen .md P1-P6 + PracticeCard Quest/Drill/Juggling).
- `game` → banner switcher sub-game (`tower|shark`) + `TowerPuzzle` atau `TypingGame`. `gameKey` untuk reset mid-session.
- `result` → `Results` (bintang, syarat, karakter tersulit, XP/koin count-up, preview iframe + tab kode/konsol JS).
- Sub-game: `subGame` state di App, default `isTouchDevice() ? "tower" : "shark"`, persist via `saveSubGame`. `selectSubGame` + switcher di banner game (tanpa kembali ke hub). `SUBGAMES[tower].mode="susun"`, `[shark].mode="ketik"`.
- `Ambient fish={!profile || screen==="dash"}` — ikan hanya di onboarding/dash.
