# 020 — Analisis Kritis HUD UI/UX (Update HUD)

**Tanggal:** 15-10-2026 20:42
**Sumber:** `.zcode-shot-full.png` / `home_hud` full-page
**Scope:** HUD Home / Peta Misi / Pilih Sub-Game / Peta Misi Samudra
**Target user:** 10–13 tahun, mode sub-game mandiri

## Ringkasan Eksekutif

Masalah utama bukan kurang info, tapi **duplikasi + jargon internal bocor + 4 CTA primer bersaing**.

1. Statistik muncul 3x dengan angka tidak konsisten (0/3 vs 0/16 vs 12).
2. Blok `Pilih Sub-Game` duplikat 100% (tombol arcade besar + kartu deskripsi).
3. 4 istilah "Peta" berbeda untuk konsep yang sama.
4. Copy verbose dan teknis untuk anak (Quest/Drill/Juggling/LocalStorage/.MD).
5. Hierarchy CTA rusak: `Main Shark Typer` vs `Main Tower` vs `Buka Peta` vs `Pelajari Materi` semua terlihat primer.

Hasil: decision paralysis, cognitive load tinggi, trust turun, 40% viewport terbuang untuk eye-candy.

## 1. Berlebihan (Redundan / Duplikat)

### 1.1 Triple Header
- Top breadcrumb: `Hub Latihan.my.id | CodeShark • mode sub-game mandiri | Coba Coding Tower →`
- Academy bar: `CODESHARK ACADEMY PETA MISI • KADET SAMUDRA LV 1 0/120 XP`
- Welcome card: `Selamat datang kembali, Kapten asdasd`

`CODESHARK ACADEMY` muncul 2x dalam 200px. `Hub Latihan.my.id` + ikon home = duplikat navigasi home.

**Fix:** 1 bar saja. Hapus welcome card sebagai blok terpisah, gabung ke academy bar.

### 1.2 Triple Statistik Tidak Konsisten
1. Kartu profil: `MISI 0/3 | AKURASI - | WPM - | COMBO - | MATERI P1-P6`
2. Strip `Peta Misi`: `MISI 0 | AKURASI - | WPM - | COMBO - | MATERI 0/16`
3. Overlay map: `MISI 12 | AKURASI 88% | WPM 45 | COMBO 32 | MATERI 4/10`

User baru 0 XP tapi map klaim 12 misi selesai. Mock vs real data tercampur.

**Fix:** 1 sumber kebenaran saja. Jika masih 0, sembunyikan stat (`—` demotivasi). Jangan pamer angka nol 3x: `0/120 XP + 0 koin + 0 XP`.

### 1.3 Dobel `Pilih Sub-Game`
- Versi A (arcade): `Main Shark Typer / Main Tower` + tombol besar
- Versi B (deskripsi): `Coding Tower PUZZLE SUSUN BLOK` vs `CodeShark SHARK TYPER`

Copy tombol muncul 4x: `Main Shark Typer` diulang di judul, tombol arcade, tag, dan kartu bawah. `Main Tower` 3x.

**Fix:** Hapus Versi A. Sisakan 1 kartu selektor dengan 1 CTA per mode.

### 1.4 Gembok Dobel
Misi terkunci tampil: ikon gembok besar + badge `Terkunci` + teks `Selesaikan Misi 01 dulu.` + pills `Materi | Praktik` yang terlihat bisa diklik.

**Fix:** 1 indikator lock saja. Pills di misi terkunci dibuat disabled jelas, bukan affordance palsu.

## 2. Overclaim / False Affordance

- `CODESHARK ACADEMY` : overclaim institusi untuk typing game. Ekspektasi universitas.
- `KADET SAMUDRA / Kapten / Rank: Plankton → Ikan Kecil` : lore berlebihan tanpa payoff gameplay. `Plankton` = rank-shaming (lemah/kecil) untuk pemula.
- `WPM TERBAIK / COMBO MAKS / AKURASI PRESISI` : bahasa esports kompetitif untuk user yang belum ketik 1 baris. Intimidatif.
- `PUZZLE SUSUN BLOK • RAMAH HP` / `SHARK TYPER • KETIK KODE` caps shouting, tidak perlu.
- Tombol arcade skeuomorphic `Main Shark Typer / Main Tower` besar tapi hanya tombol biasa. Makan 40% viewport.
- `Coba Coding Tower →` di topbar memaksa pindah mode saat user sudah di mode CodeShark.
- `MATERI HTML P1-P6 (.MD)` : ekstensi file bocor ke UI.

## 3. Verbose (Tidak Efisien Bahasa)

Target 10-13 tahun, tapi copy seperti dokumentasi dev:

- `Selamat datang kembali,` : hapus, basi dilihat tiap kunjungan.
- `Susun blok HTML/CSS/JS sesuai urutan menjadi menara. Ketuk saja — tanpa keyboard fisik.` + pengulangan di tags: `Tanpa mengetik simbol, Tombol besar sentuh, Ada petunjuk & undo`. Cukup 1 baris: `Susun balok jadi menara. Ketuk saja.`
- `Ketik ulang kode persis seperti aslinya sambil mengusir hiu. Butuh keyboard fisik.` Cukup: `Ketik kode, usir hiu.`
- Box kurikulum: `Tiap pertemuan: materi → Quest (kode utuh) → Drill (sintaks inti) → Juggling (anyam dua materi) — dimainkan sebagai Shark Typer` . Jargon internal (Quest/Drill/Juggling) tidak perlu diketahui user.
- `Satu kurikulum 16 pertemuan dua cara main— progres XP, koin & bintang berlaku untuk keduanya.` Ukuran 10px, tidak terbaca.
- `Alur: Materi - Praktik Ketik - Preview` tidak menjelaskan aksi.
- Footer: `progres tersimpan di LocalStorage perangkatmu.` Terlalu teknis. Cukup: `Otomatis tersimpan di perangkat ini.`
- `16 pertemuan • UTS 8 • UAS 16` : membingungkan, kemungkinan typo UTS/UAS.

## 4. Tidak Efektif & Tidak Efisien (Hierarchy & Usability)

### 4.1 4 CTA Primer Bersaing
`Main Shark Typer [orange]` vs `Main Tower [biru]` vs `Buka Peta [kuning]` vs `Pelajari Materi [kuning]`.

User baru harusnya 1 next action: `Pelajari Materi Misi 01`. Sisanya secondary/link.

### 4.2 Map Cantik Tapi Tidak Scannable
Isometrik dome + node `10,11,12,13` tidak terbaca, kontras rendah, overlay gelap, teks `Mengenal HTML & Alat Perangny` terpotong. Eye-candy over usability.

### 4.3 Inkonsistensi Denominator
`MISI 0/3` vs `0/16` vs `MISI 01,02,03`. `16 pertemuan` vs `P1-P6`. User tidak tahu total misi sebenarnya.

### 4.4 Navigasi Ganda
`Hub Latihan.my.id` (teks) + ikon home kanan atas + `Buka Peta` + `Pelajari Materi`. Terlalu banyak jalan keluar tanpa hierarki.

## 5. Rekomendasi Prioritas (Potong 50% HUD)

**P0 - Wajib:**
1. Gabung 3 statistik → 1 strip. Sembunyikan jika 0.
2. Hapus blok arcade `Main Shark Typer / Main Tower`. Sisakan 1 selektor mode.
3. Tetapkan 1 Primary CTA: `Pelajari Materi Misi 01`. Demote sisanya ke secondary.
4. Samakan istilah: pilih 1 saja, misal `Peta Misi`. Hapus `Peta Pertemuan 16x / Buka Peta / Peta Misi Samudra` sebagai judul terpisah.

**P1 - Copy:**
5. Hapus jargon: Quest/Drill/Juggling/LocalStorage/.MD/P1-P6 dari UI user.
6. Sederhanakan deskripsi mode jadi ≤12 kata per mode.
7. Ganti `Rank: Plankton` → netral, misal `Level 1 - Kadet Baru`. Hindari shaming.
8. Footer: `Otomatis tersimpan`.

**P2 - Visual:**
9. Naikkan kontras node map, besarkan hit-area, potong overlay stat di atas map.
10. Lock state: 1 ikon + 1 teks saja. Disabled pills jelas.
11. Topbar: hapus `Coba Coding Tower →` jika sudah ada selektor di body. Hapus salah satu display XP ganda.
