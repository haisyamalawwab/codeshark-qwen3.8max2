## 🐛 TROUBLESHOOTING

### Problem 1: "git rm" gagal karena file tidak ada

```bash
# Error:
fatal: pathspec 'node_modules/' did not match any files

# Solution: File memang sudah tidak ter-track, lanjutkan saja
git add .gitignore
git commit -m "chore: update .gitignore"
```

### Problem 2: Masih ada files ter-track setelah cleanup

```bash
# Check apa saja yang masih ter-track
git ls-files | grep node_modules

# Jika masih ada, force remove:
git rm --cached -r node_modules/
git commit --amend --no-edit
```

### Problem 3: Merge conflict di .gitignore setelah pull

```bash
# Accept incoming changes (new comprehensive .gitignore)
git checkout --theirs .gitignore
git add .gitignore
git commit --no-edit
```

### Problem 4: Accidentally committed secrets (.env)

```bash
# 1. Remove from current commit
git rm --cached .env
git commit --amend --no-edit

# 2. If already pushed, rewrite history (DANGEROUS!)
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch .env" \
  --prune-empty --tag-name-filter cat -- --all

# 3. Force push (coordinate with team!)
git push --force --all

# 4. ROTATE SECRETS immediately!
```

## 📖 EDUCATIONAL NOTES

### Untuk Siswa/Mahasiswa:

**Q: Kenapa node_modules tidak di-commit?**

A: Tiga alasan utama:
1. **Size**: 100MB+ untuk project medium-size
2. **Redundancy**: Semua info sudah ada di `package.json`
3. **Platform-specific**: Native modules berbeda per OS

**How it works:**
```
Developer A:
package.json + package-lock.json
         ↓
    npm install
         ↓
   node_modules/ (150MB)

Push to Git:
package.json + package-lock.json (100KB)

Developer B:
git clone (download 100KB)
         ↓
    npm install
         ↓
   node_modules/ (150MB, identical!)
```

**Q: Kenapa dist/ tidak di-commit?**

A: Build artifacts adalah **output**, bukan **input**:
- Setiap deploy otomatis run `npm run build` → generate `dist/`
- Build result bisa beda tergantung environment (dev vs prod)
- Tidak ada manfaatnya version control file yang auto-generated

## 🎯 NEXT STEPS (OPSIONAL)

### 1. Setup Pre-commit Hook (prevent future mistakes)

```bash
# Install Husky
npm install --save-dev husky

# Setup pre-commit hook
npx husky install
npx husky add .husky/pre-commit "git diff --cached --name-only | grep -q '.env' && echo '❌ Cannot commit .env files!' && exit 1 || exit 0"
```

### 2. Setup Git LFS (jika ada large binary files)

```bash
# Install Git LFS
git lfs install

# Track large files (contoh: video tutorial)
git lfs track "*.mp4"
git lfs track "*.mov"

# Commit .gitattributes
git add .gitattributes
git commit -m "chore: setup Git LFS for video files"
```

### 3. Setup GitHub Actions CI (automated checks)

```yaml
# .github/workflows/check-secrets.yml
name: Check Secrets
on: [push, pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Check for committed secrets
        run: |
          if git ls-files | grep -E '\.env$'; then
            echo "❌ .env file committed!"
            exit 1
          fi
```
